# Anime Edit Studio v2：合并前状态

日期：2026-07-26
目标分支：`master`

## 本次完成的核心改动

### 参考风格与节奏

- `StyleFingerprint` 增加运动方向、运动幅度、开场和收尾节奏指标。
- `EditingStyleProfile` 增加运动中位数、P75、动态范围、Hold 比例、方向平衡和反转率。
- Sequence Planner 支持参考片驱动的 Hook 快切、全局切点密度约束和受控减速收尾。

### Motion Choreography

- EditSpec 升级到 `2.1.0`，增加跨镜头 `MotionPhrase`。
- Resolve 使用单个 Fusion comp 组合 `TimeStretcher + Transform + DirectionalBlur`，
  避免多个 Fusion comp 实际只是版本而不是串联节点栈。
- `timespeed_recipe`、双侧 Whip/Blur transition 和 `motion_phrase_compositor`
  均经过 Resolve 21.0.3.7 真实渲染验证。
- 新增确定性 Motion QA：运动强度、动态范围、Hold、方向平衡、反转和跨切点连续性。

### 锁画与母版

- 新增确定性锁画 finishing：锁定所有画面决策，只允许调色、声音、母版素材和交付设置变化。
- Color Recipe 形成干净基线、火焰推进、高反差和红色冲击的有限色彩弧线。
- Sound Recipe 使用预烘焙 WAV 兜底，避免依赖不可用的 Fairlight Automation。
- Final QA 的预期静止范围统一读取 Shot 数据，CLI 与 Review UI 不再对有意 Hold
  给出不同结论。
- 新增将超分 mezzanine 重新送入 Resolve delivery timeline 的最终渲染路径。

## 当前已知问题

### 1. 4K 超分尚未成为单一 CLI 命令

锁画、Resolve mezzanine、逐帧 Real-ESRGAN、4K mezzanine、Resolve delivery 和最终 QA
已经真实跑通，但目前仍是多个确定性步骤的组合。下一步应封装为可恢复的
`aes finish` 作业，并记录每一步缓存 key、状态和失败恢复信息。

### 2. Real-ESRGAN 的安装发现不等于真实可运行

当前 macOS 安装必须显式传递绝对模型目录 `-m .../models`。只发现可执行文件会把能力
误报为 available，直接运行会异常退出。工具发现应增加模型文件校验和最小真实 probe。

### 3. Fairlight Automation 仍不可用

Resolve 21.0.3.7 公共脚本 API 不能写音量关键帧、轨道自动化或 Pan。当前正式路径是
确定性预烘焙 48 kHz 音频并导入多轨，结果可交付，但不能覆盖所有人工 Fairlight
混音能力。

### 4. 部分 Resolve 能力仍未完成语义映射

- `retime_interpolation_mapping`：整数 0–3 可写，但每档视觉语义未完成对照。
- `export_lut`、`stabilize`、`scene_cut_detection`、`subtitles_from_audio`：
  方法已探测但未完成输出验收。
- `camera_move_recipe`、`gui_automation`：尚未验证；GUI 自动化继续默认关闭。

### 5. 原生主体跟踪与 Smart Reframe 不可用

`CreateMagicMask` 调用失败，`SmartReframe` 返回成功但渲染无变化。系统必须继续使用
自研主体检测加已验证的 Pan/Zoom transform，不能恢复为原生能力假设。

### 6. 工作流状态与离线生产需要统一

Review UI 使用 SQLite 状态机；本次 V3 从 CLI/离线链生成，锁画和交付证据保存在项目文件，
但没有完整历史状态序列。后续所有 CLI 生产也应写入同一状态机，避免 UI 与 CLI
出现两个项目状态真相来源。

### 7. 产品审美验收仍需扩展样本

炼狱杏寿郎只证明第一种参考节奏和角色风格可以完整交付。多种剪辑风格、其他角色、
不同音乐结构和长短片仍需逐条作品验证，不能从单条成片推导为全风格通过。

## 合并验收

合并前必须满足：

- 文档引用无断链，根目录无散落项目文档。
- `git diff --check` 通过。
- 完整测试套件通过。
- 不提交 `projects/`、数据库、代理、超分帧缓存和交付视频。
- `v2` 推送后再以可追溯 merge commit 合并到 `master`。
