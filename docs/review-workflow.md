# Review Workflow

1. 先创建 Brief。
2. 为项目绑定素材池。
3. 启动 `anime review serve <project_id>`。
4. 在 Review Web 中逐镜头执行 use / alternate / reject。
5. 用 `I` / `O` 设入出点。
6. 生成 Blueprint。
7. 检查 Rights Report。
8. 选择 Variant，生成 `editspec.final.variant-*.json`。

快捷键：

- `Space` 播放/暂停
- `←` `→` 切镜头
- `1` `2` `3` 写回 use / alternate / reject
- `H B S W D F C` 追加原因
- `I O` 设置入点/出点
